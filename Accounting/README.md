# とうじょうRMO会計システム（Accounting）

支払基準・税込の会計システムです。画面（HTML）はこのフォルダ、データの読み書きは Google Apps Script（GAS）の Web API、データは Google スプレッドシートに保存します。

```
[このフォルダの HTML / JS] ──POST──▶ 会計API（GAS）──▶ 会計Ledger（スプレッドシート）＋ 証憑フォルダ（Drive）
   集計・表示はすべてここ     └─POST──▶ 予算API（GAS）──▶ 予算管理（スプレッドシート）
```

---

## 0. 開発方針

| 対象 | 方針 |
|---|---|
| **GAS（会計API・予算API）** | **変更しない。** 読み書きと入力チェックだけを持ち、集計・表示のロジックは持たない |
| **スプレッドシート** | **構造（シート・既存列の見出し）は変えない。** マスタの行（勘定科目・支払元・設定・予算）は自由に更新してよい。列は要望に応じて**追加**できる |
| **HTML / JS / CSS** | **要望に応じて柔軟に変える。** 集計（BS・PL・推移・予算対比）もここで行う |

GAS を変えずに済むように、API は次のように作っています。

- **見出し名で読み書き**：列の位置ではなく 1 行目の見出し名で扱うので、列を追加・移動しても GAS は影響を受けません
- **生データを返す**：`getLedger` は仕訳帳の全行、`getConfig` は設定と「〜マスタ」という名前の全シートを、追加列も含めてそのまま返します
- **追加列への書き込み**：登録時に `payload.extra = { 見出し名: 値 }` を渡すと、その列に書き込みます（システムの列は上書きできません）
- **集計は `js/model.js`**：BS・PL・月次推移・資金残高・予算対比はブラウザで計算します

### よくある変更の進め方

| やりたいこと | 変更する場所 |
|---|---|
| 勘定科目・支払元・資金原資の選択肢を増やす | スプレッドシートのマスタ・設定タブだけ（画面に自動反映） |
| 新しいマスタを作る | 会計Ledger に「〇〇マスタ」という名前のシートを追加 → `getConfig().masters['〇〇マスタ']` で取得できる |
| 仕訳帳に列を追加して入力・表示する | ① 仕訳帳の右端に見出し付きで列を追加 ② `js/config.js` の `COLS.ledger` に `キー: '見出し名'` を追加 ③ 入力画面で `data.extra = { '見出し名': 値 }` を送る ④ 表示・集計は `js/model.js` / 各ページの JS で `record.キー` を使う |
| 予算シートに列を追加 | 予算シートに列を追加 → `COLS.budget` に追加 |
| 画面・集計を変える | `*.html`・`js/`・`css/` を修正。集計を変えたら `node tests/model.test.js` で確認 |

> どうしても GAS を変える必要がある場合（新しい書き込み処理など）は、既存の API を残したまま追加し、`gas/`・`gas-budget/` の控えと README を更新してください。

### API

どちらも `POST`（`Content-Type: text/plain`）で `{ action, args, key }` を送り、`{ ok, data }` または `{ ok:false, code?, error }` が返ります（`code:'AUTH'` はパスコード違い）。

| API | action | 内容 |
|---|---|---|
| 会計API | `getConfig()` | `settings`（設定タブ）、`accounts`・`sources`（マスタ、無効行を含む）、`masters`（「〜マスタ」全シート）、`ledgerHeaders`、`today` |
| 会計API | `getLedger()` | 仕訳帳 `{ headers, rows }`（日付は `yyyy-MM-dd`） |
| 会計API | `submitTransaction(payload)` | 支払・収入の登録（入力チェック、証憑保存、仕訳ID採番） |
| 会計API | `submitJournal(payload)` | 仕訳（複合仕訳可）の登録 |
| 予算API | `getBudget()` | `{ versions: [{ name, kind, date, headers, rows }] }`（`当初予算_` / `改訂予算_` シート、日付順） |

payload の項目は `gas/Code.gs` の各関数のコメントを参照してください。

## 2. 使い方（利用者向け）

1. `index.html` を開く（GitHub Pages など、またはローカルで直接開いても可）
2. 初回はパスコードを入力（ブラウザに保存されます。消すときはヘッダーの **Logout**）
3. メニューから各画面へ

| 画面 | できること |
|---|---|
| 支払・収入入力 | 支払元（小口現金／銀行口座／個人立替）と勘定科目、税込金額、摘要などを入力し、証憑をドラッグ＆ドロップで添付して登録。予算小項目を選ぶと勘定科目・資金原資が自動入力され、実績が予算対比に集計されます |
| 仕訳入力 | 借方・貸方を直接入力。貸借が一致すると登録できます |
| ダッシュボード | 会計年度を選んで BS・PL・推移・予算対比を表示。予算対比は表示する予算バージョンと階層（大項目／中項目まで／小項目まで）を切り替え、行クリックで開閉 |

## 3. 運用ルール

- **支払基準**：実際に支払った日・入金された日で入力します。請求書を受け取っただけ（未払）や見込は入力しません
- **税込経理**：金額は税込で記録。消費税額は参考情報として保持します
- **個人立替**：支払元「個人立替（精算待ち）」で入力 → 借方 費用／貸方 未払金。精算したら仕訳入力の「立替精算」テンプレート（借方 未払金／貸方 普通預金）
- **期首残高**：仕訳入力の「開始残高」テンプレート（借方 普通預金・小口現金／貸方 正味財産（繰越金））
- **資金原資の分類**：
  - 支出の財源は **RMO交付金** と **自己資金** の2区分。費用を支払うときは必ず選択します（入力画面で必須）
  - 収入は **RMO交付金収入**（→ RMO交付金）と **事業収入**（→ 自己資金）の2区分。収入科目を選ぶと資金原資は自動で決まります（勘定科目マスタの「資金区分」列）
- **訂正**：行は削除せず、仕訳帳の「状態」を `取消` にして正しい仕訳を入れ直します（集計から除外されます）

## 4. スプレッドシートの構成

### 会計Ledger

| シート | 内容 |
|---|---|
| 仕訳帳 | Ledger 本体。1行＝借方1件・貸方1件（どちらか片方でも可）。同じ仕訳IDの行で複合仕訳 |
| 勘定科目マスタ | 科目の追加・停止（「有効」を FALSE）。「入力画面」列で支払／収入画面に出す科目を指定。「資金区分」列で収入科目の資金原資を指定（RMO交付金収入→RMO交付金、事業収入→自己資金） |
| 支払元マスタ | 小口現金／銀行口座（普通預金）／個人立替（未払金）。種別「現金」「銀行」が資金残高の対象 |
| 試算表 | 合計残高試算表（関数で自動計算）。中央に勘定科目、左に借方、右に貸方。BS科目は年度末累計、PL科目は当年度。前期までの収支差額は「前期繰越収支差額」行に表示。D2 が 0 なら貸借一致 |
| 設定 | 期首月、対象会計年度、証憑フォルダID、仕訳ID接頭辞、資金原資の選択肢（カンマ区切り）など |

仕訳帳の列：

| 列 | 項目 | 列 | 項目 |
|---|---|---|---|
| A | 仕訳ID | M | 取引先 |
| B | 行No | N | インボイス登録番号 |
| C | 取引日 | O | 摘要 |
| D | 計上月 | P | 申請書予算項目（予算中項目名） |
| E | 会計年度 | Q | 資金原資 |
| F | 入力区分（支払／収入／仕訳／移行） | R | 証憑番号 |
| G | 借方科目 | S | 証憑URL |
| H | 借方金額 | T | 入力者 |
| I | 貸方科目 | U | 登録日時 |
| J | 貸方金額 | V | 状態（有効／取消） |
| K | 税率 | W | 予算コード（予算小項目） |
| L | 消費税額 | | |

### 予算管理

- 予算はバージョンごとに1シート。シート名は **`当初予算_YYYY-MM-DD`** または **`改訂予算_YYYY-MM-DD`**（この形式のシートだけを予算として読みます）
- 列：予算コード／予算大項目／予算中項目／予算小項目／勘定科目／資金原資／MoSCoW／単価／月数／数量／単位／予算額（総事業費）／うちRMO交付金／うち自己資金／メモ
- 予算額は「単価×月数×数量」の数式。一括額のときは単価〜数量を空にして直接入力して構いません
- **改訂のしかた**：最新シートを複製 → 名前を `改訂予算_改訂日` に → 金額を修正。同じ項目は同じ予算コードのまま、新しい項目は未使用のコードを追加
- **実績の紐づけ**：仕訳帳の「予算コード」（入力画面で予算小項目を選ぶと入る）。コードが無い仕訳は「申請書予算項目」を予算中項目として集計し、ダッシュボードでは「（小項目未設定）」として赤字表示

> 仕訳帳・マスタの列は **見出し名** で読み書きしています。列の並び替えや追加をしても動きますが、上の見出し名は変えないでください。

## 5. セットアップ手順（新しく作り直す場合）

既存環境はセットアップ済みです。別環境に複製するときや作り直すときの手順です。

### 5-1. スプレッドシートと Drive

1. Drive にフォルダ「とうじょうRMO会計システム」と、その中に「証憑」フォルダを作成
2. 会計Ledger・予算管理のスプレッドシートを用意（既存のものを「コピーを作成」すると早い）
3. 会計Ledger の「設定」タブ「証憑フォルダID」に証憑フォルダの ID を入れる

### 5-2. 会計API（Apps Script）

1. 会計Ledger を開き［拡張機能］→［Apps Script］
2. `コード.gs` を `gas/Code.gs` の内容で置き換え、`SPREADSHEET_ID` を会計Ledger の ID に変更して保存
3. 関数 `initApiKey` を選んで［実行］→ 権限を承認（「詳細」→「安全ではないページに移動」→「許可」）
4. ［プロジェクトの設定］→「スクリプト プロパティ」で `API_KEY` の値をパスコードに設定
5. ［デプロイ］→［新しいデプロイ］→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（外部の HTML から呼ぶため。「組織内の全員」では動きません）
6. 表示されたウェブアプリ URL（`…/exec`）を控える

### 5-3. 予算API（Apps Script）

1. 予算管理を開き［拡張機能］→［Apps Script］
2. `コード.gs` を `gas-budget/Budget.gs` の内容で置き換え、`BUDGET_SPREADSHEET_ID` を変更して保存
3. `initApiKey` を実行して権限を承認
4. スクリプトプロパティ `API_KEY` を会計API と**同じパスコード**に設定
5. 会計API と同じ設定（自分／全員）でウェブアプリとしてデプロイし、URL を控える

### 5-4. HTML

`js/config.js` の `CONFIG` を書き換えます。

```js
API_URL: '会計API の …/exec',
BUDGET_API_URL: '予算API の …/exec',
LEDGER_URL: '会計Ledger スプレッドシートの URL',
BUDGET_URL: '予算管理スプレッドシートの URL',
```

### 5-5. 動作確認

- ブラウザで各 `…/exec` を開き、`{"ok":true,"data":{"service":"…","version":2, …}}` が出ること
- `index.html` を開いてパスコードを入力し、ダッシュボードが表示されること
- 集計ロジックのテスト：`node tests/model.test.js`（Node.js 18 以上）

## 6. 保守

| やりたいこと | 手順 |
|---|---|
| 画面・集計を変える | このフォルダのファイルを修正。集計を変えたら `node tests/model.test.js` |
| 勘定科目・支払元を追加 | 会計Ledger の各マスタに行を追加（画面と試算表に自動反映） |
| 資金原資の選択肢を変える | 会計Ledger「設定」タブ「資金原資」（カンマ区切り、現在は RMO交付金,自己資金）。収入側は勘定科目マスタ「資金区分」 |
| 損益計算書の売上区分を変える | `js/config.js` の `SALES_ACCOUNTS` |
| 会計年度を切り替える | ダッシュボードは画面で選択。試算表は「設定」タブ「対象会計年度」 |
| パスコードを変える | 会計API・予算API の両方でスクリプトプロパティ `API_KEY` を同じ値に変更（再デプロイ不要）。利用者は次回アクセス時に再入力 |
| （例外）GAS を修正して反映 | Apps Script で保存 →［デプロイ］→［デプロイを管理］→ 鉛筆 → バージョン「新バージョン」→［デプロイ］（URL は変わりません）。`gas/`・`gas-budget/` の控えも更新 |

### トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 「パスコードが違います」 | 入力ミス、または `API_KEY` が変更された。正しいパスコードを再入力 |
| 「サーバー側のパスコードが未設定です」 | スクリプトプロパティ `API_KEY` が未設定。5-2 / 5-3 の手順4 |
| データが読み込めない（ネットワークエラー、401） | デプロイのアクセスが「全員」になっていない。［デプロイを管理］→ 鉛筆 → アクセスできるユーザー「全員」→［デプロイ］ |
| 「js/config.js の API の URL が未設定です」 | `js/config.js` の `API_URL` / `BUDGET_API_URL` を設定 |
| 「仕訳帳に列「〇〇」がありません」 | 仕訳帳の見出し名が変わっている。4. の見出し名に戻す |
| 追加した列が画面に出ない | `js/config.js` の `COLS` に追加したか確認（見出し名は完全一致） |
| 予算対比に「（小項目未設定）」が出る | その仕訳に予算コードが無い。仕訳帳の予算コード列に入れるか、入力時に予算小項目を選ぶ |
| 試算表の貸借差額（D2）が赤い | 貸借が一致しない仕訳がある。ダッシュボード上部の警告で仕訳IDを確認 |

## 7. 補足

- 初期データ：仕訳帳 J000001〜J000009 は旧「支出Ledger_2026年度」の確定分（入力区分＝移行、すべて個人立替）
- 当初予算は RMO_予算.xlsx（明細シート）から作成。大項目＝申請書予算項目REV、中項目＝申請書予算項目、小項目＝摘要
- 予算対比の予算額は総事業費（自己資金を含む）。残額・執行率は表示中の最新バージョンが基準
- 2026-11 にリファクタリング（v2）：集計を GAS から HTML 側（`js/model.js`）へ移し、GAS は読み書き専用に。旧 `common.js`・ルートの `style.css` は `js/`・`css/` に分割
- 認証はパスコードのみ。URL とパスコードを知っていればアクセスできるため、パスコードは必要に応じて長いものに変更してください
