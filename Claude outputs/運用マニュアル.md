# とうじょうRMO会計システム 運用マニュアル

対象：会計の入力・確認を担当する運用メンバー
最終更新：2026年11月23日

このマニュアルでは、日々の支払・入金の入力と、ダッシュボードでの確認方法を説明します。
システムの設定変更や修正はすべてエンジニアが行います。運用メンバーは **入力と確認** だけを行い、それ以外は「9. エンジニアへの依頼」の方法で依頼してください。

---

## 1. このシステムでできること

| できること | 使う画面 |
|---|---|
| 支払・入金を1件ずつ登録し、領収書などの証憑を保存する | 支払・収入入力 |
| 立替金の精算や期首残高などを登録する | 仕訳入力 |
| 貸借対照表・損益計算書（事業別）・予算の執行状況を見る | ダッシュボード |

入力した内容は Google スプレッドシート「02_会計Ledger」に記録され、証憑は Google ドライブの「Accounting System ＞ 証憑 ＞ 年-月」フォルダに保存されます。

## 2. 基本のルール（必ず守ってください）

1. **支払った日・入金された日に入力する**
   この会計は「支払基準」です。請求書や見積書を受け取っただけでは入力しません。実際にお金が動いた日付で入力します。
2. **金額は税込で入力する**
   消費税額は自動で計算されます（手で直すこともできます）。
3. **証憑（領収書・請求書など）を必ず添付する**
   スマートフォンで撮った写真や PDF で構いません。
4. **支出は必ず「資金原資」を選ぶ**
   支出の財源は **RMO交付金** か **自己資金** のどちらかです。わからないときは登録前に担当者に確認してください。
5. **収入・支出は必ず「事業」を選ぶ**
   どの事業の売上・費用かを選びます。どの事業とも特定できない費用は **共通** を選んでください（一般管理費になります）。RMO交付金収入は自動で「共通」になります。
6. **予算項目を選ぶ**
   支出は、できるだけ「予算大項目 → 中項目 → 小項目」を選んでください。選ばないと、予算対比で「（小項目未設定）」として赤字表示されます。
7. **一度登録したものは自分で消さない**
   間違えたときは「6. 間違えたときは」の手順に従ってください。

### 資金原資の考え方

| 区分 | 収入 | 支出 |
|---|---|---|
| RMO交付金 | RMO交付金収入（交付金の入金） | 交付金の対象となる経費 |
| 自己資金 | 事業収入（販売・参加費など） | 交付金の対象外の経費 |

収入は科目を選ぶと資金原資が自動で決まります（RMO交付金収入 → RMO交付金、事業収入 → 自己資金）。

### 事業の考え方

損益計算書は事業ごとに「売上・原価・粗利」を出し、最後に一般管理費を引いて最終利益を出します。

| 選ぶ事業 | 収入（収益）は | 支出（費用）は |
|---|---|---|
| 農業体験事業・ブランド米事業・スマート農業事業・お弁当販売事業 など | その事業の **売上** | その事業の **原価** |
| 共通（どの事業とも特定できない） | **共通収入**（RMO交付金収入など） | **一般管理費** |

例：米ラベルの印刷代 → ブランド米事業、Google Workspace や法人印鑑 → 共通、体験イベントの参加費 → 農業体験事業。
事業の一覧はエンジニアが管理しています。新しい事業を始めるときは「9. エンジニアへの依頼」で追加を依頼してください。

## 3. はじめに（ログイン）

1. 担当者から案内された **会計システムのURL** を開きます（メニュー画面が表示されます）
2. 「Enter Password.」と表示されたら、担当者から伝えられた **パスコード** を入力して「OPEN ACCOUNTING」を押します
3. パスコードはそのブラウザに保存されるので、次回からは入力不要です

- 共用のパソコンを使った場合は、終わったら画面右上の **LOGOUT** を押してください（保存されたパスコードが消えます）
- 「パスコードが違います」と表示されたら、パスコードが変更されている可能性があります。担当者に確認してください

### 画面の見かた

画面上部のメニューで移動します。

| メニュー | 画面 |
|---|---|
| MENU | メニュー（タイル） |
| ENTRY | 支払・収入入力 |
| JOURNAL | 仕訳入力 |
| DASHBOARD | ダッシュボード |
| LEDGER ↗ | 会計Ledger（スプレッドシート）を別タブで開く |
| BUDGET ↗ | 予算管理（スプレッドシート）を別タブで開く |

入力欄は薄い青の枠で表示されます。赤い **必須** マークがある欄は必ず入力してください。

## 4. 支払・収入を入力する（ENTRY）

日々の入力はほとんどこの画面で行います。

### 4-1. 支払を入力する

1. 画面上部の切り替えで **支払** を選びます
2. 次の項目を入力します

| 項目 | 入力内容 |
|---|---|
| 取引日 | 実際に支払った日 |
| 支払元 | お金を出した先：**小口現金**／**銀行口座（普通預金）**／**個人立替（精算待ち）** |
| 勘定科目 | 費用の種類（通信費、消耗品費など）。一覧にない場合は「すべての科目を表示」にチェック |
| 取引先 | 支払った相手（例：ラクスル株式会社） |
| 金額（税込） | 領収書の合計金額 |
| 税率 | 通常は 10%。食品は 8%、両方ある場合は「8%・10%」 |
| 消費税額 | 自動計算。領収書と違う場合は直す |
| インボイス登録番号 | 領収書に「T＋13桁」があれば入力 |
| 摘要 | 何に使ったか（例：名刺印刷 200部（送料込）） |
| 資金原資 | **RMO交付金** か **自己資金**（必須） |
| 事業 | どの事業の費用か（必須）。特定できない場合は **共通**（一般管理費） |
| 予算大項目・中項目・小項目 | 予算のどの項目の支出か。小項目を選ぶと勘定科目・資金原資が自動で入ることがあります |
| 証憑番号 | 領収書番号・請求書番号など |
| 入力者 | 自分の名前 |

3. **証憑の添付** 欄に、領収書の写真や PDF をドラッグ＆ドロップ（またはクリックして選択）します。複数添付できます
4. 下の **仕訳イメージ** で「（借方）通信費 ／（貸方）小口現金」のように表示されることを確認します
5. **登録する** を押します。右下に「登録しました：J000010」のように仕訳IDが表示されれば完了です

> 証憑を添付せずに登録しようとすると確認メッセージが出ます。原則として証憑は添付してください。

### 4-2. 個人が立て替えた支払

個人のクレジットカードや現金で払った場合は、**支払元を「個人立替（精算待ち）」** にして入力します。
あとで立替者に精算（返金）したときに、「5-2. 立替金を精算する」の手順で登録します。

### 4-3. 収入を入力する

1. 画面上部の切り替えで **収入** を選びます
2. 次の項目を入力します

| 項目 | 入力内容 |
|---|---|
| 取引日 | 入金された日 |
| 入金先 | **銀行口座（普通預金）** または **小口現金** |
| 勘定科目 | **RMO交付金収入**（交付金の入金）または **事業収入**（販売・参加費など） |
| 金額 | 入金額 |
| 摘要 | 例：RMO交付金 概算払（第1回） |
| 資金原資 | 科目を選ぶと自動で入ります（変更不可） |
| 事業 | 事業収入はどの事業の売上かを選ぶ（必須）。RMO交付金収入は自動で「共通」 |

3. 通帳のコピーや入金通知などがあれば添付し、**登録する** を押します

## 5. 仕訳入力（JOURNAL）

支払・収入入力では登録できない取引に使います。借方と貸方の金額が一致すると **仕訳を登録** ボタンが押せるようになります。

### 5-1. 期首残高（年度の始め・最初の1回）

1. **テンプレート：開始残高** を押します
2. 普通預金・小口現金の行に、年度開始時点の残高を入力します
3. 正味財産（繰越金）の行に、その合計を入力します
4. 「✓ 貸借一致」と表示されたら **仕訳を登録** を押します

### 5-2. 立替金を精算する

個人立替で入力した支払を、立替者に返金したときに登録します。

1. **テンプレート：立替精算** を押します
2. 借方「未払金」と貸方「普通預金」（現金で返した場合は「小口現金」に変更）に、返金額を入力します
3. 摘要に「〇〇さん立替分の精算（10月分）」のように書きます
4. **仕訳を登録** を押します

### 5-3. その他

口座間の資金移動（銀行から小口現金への引き出しなど）も仕訳入力で登録します。
例：銀行から現金 10,000 円を引き出した → 借方「小口現金」10,000 ／ 貸方「普通預金」10,000

**事業の入れ方**：伝票情報の「事業」は、明細で事業を選ばなかった行に入ります。1枚の請求書を複数の事業に分けるときは、明細の行ごとに「事業」を選んでください（例：1行目 ブランド米事業 3,000円、2行目 共通 2,000円）。費用・収益の科目がない仕訳（立替精算や資金移動）は事業を選ばなくても登録できます。

判断に迷う取引は、登録する前に担当者に相談してください。

## 6. 間違えたときは

**登録した内容は自分で削除・修正しないでください。** 次の情報をエンジニアに連絡してください。

- 仕訳ID（登録時に表示された J000010 など。ダッシュボード下部の一覧でも確認できます）
- 何が間違っているか（金額、日付、科目、資金原資、事業など）
- 正しい内容

エンジニアが元の仕訳を「取消」にして、正しい内容に直します（取消した仕訳は集計に含まれません）。

## 7. ダッシュボードの見かた（DASHBOARD）

画面右上の **FISCAL YEAR** で会計年度（4月〜翌3月）を選びます。**更新** で最新の状態に読み直します。

| 表示 | 内容 |
|---|---|
| 主要な数値 | 資金残高（小口現金＋普通預金）、資産・負債・純資産、当期の収益・費用・収支差額 |
| 貸借対照表 | 左に資産、右に負債・純資産。年度末時点の残高 |
| 損益計算書（事業別） | 事業ごとの売上・原価・粗利 → 粗利合計 − 一般管理費 ＝ 事業損益 → ＋ 共通収入（RMO交付金収入など）＝ 最終利益（当期収支差額） |
| 費用の内訳 | 勘定科目別の費用のグラフ（カーソルを合わせると金額を表示） |
| 月次の収益・費用 | 月ごとの収益（濃い青）と費用（明るい青） |
| 資金残高の推移 | 月末時点の小口現金＋普通預金 |
| 予算対比 | 予算と実績の比較（下記） |
| 当年度の仕訳 | 新しい順に15件。証憑の「開く」で添付ファイルを表示 |

### 予算対比の見かた

- **表示する予算**：当初予算・改訂予算のうち、表示したいものをクリックで選びます（複数可）
- **階層**：「大項目」「中項目まで」「小項目まで」で表示する細かさを切り替えます。行をクリックするとその下を開閉できます
- **実績**：会計Ledger から自動で集計した支出額（常に表示）
- **残額・執行率**：表示している予算のうち一番新しいものとの比較。予算を超えるとバーと数字が赤くなります。ただし小項目・中項目が超えていても、上の項目（中項目・大項目）の合計が予算内であれば赤くなりません
- **（小項目未設定）**：予算項目を選ばずに登録した支出。どの項目か分かる場合はエンジニアに連絡してください

### 画面上部に赤い警告が出たら

「貸借が一致しない仕訳があります」などの警告が表示された場合は、表示内容をそのままエンジニアに連絡してください。

## 8. 毎月のチェックリスト

月末または翌月初めに次を確認してください。

- [ ] その月の領収書・請求書（支払済み分）がすべて入力されている
- [ ] すべての支払に証憑が添付されている
- [ ] 支出の資金原資（RMO交付金／自己資金）が正しい
- [ ] 収入・支出の事業が正しい（ダッシュボード下部の一覧の「事業」列で確認。損益計算書に「（事業マスタにない）」が出ていない）
- [ ] 予算対比に「（小項目未設定）」が残っていない
- [ ] ダッシュボードの資金残高が、通帳残高＋手元現金と一致している
- [ ] 個人立替のうち精算済みのものは「立替精算」を登録した

## 9. エンジニアへの依頼

次のことは運用メンバーでは行わず、エンジニアに依頼してください。

| 依頼内容 | 例 |
|---|---|
| 登録内容の訂正・取消 | 金額を間違えた、二重に登録した |
| 勘定科目・支払元の追加 | 新しい費用の種類、新しい銀行口座 |
| 予算の改訂 | 予算額の変更、項目の追加（「改訂予算_日付」として追加されます） |
| パスコードの変更・再発行 | パスコードを忘れた、変更したい |
| 画面の不具合 | エラーが出る、表示がおかしい |

### 依頼するときに伝えること

- いつ・どの画面で・何をしたか
- 表示されたメッセージ（画面のスクリーンショットがあると確実です）
- 関係する仕訳ID

## 10. よくある質問

**Q. 勘定科目がわからない**
A. 迷ったら担当者に確認してください。よく使う例：電話・ドメイン・クラウドサービス → 通信費／名刺・チラシ → 印刷製本費／文房具・小物 → 消耗品費／会議の飲食 → 会議費

**Q. 請求書を受け取ったが、まだ払っていない**
A. まだ入力しません。支払った日に入力します。

**Q. 1枚の領収書に食品（8%）と日用品（10%）が混ざっている**
A. 税率を「8%・10%」にし、消費税額は領収書に記載の合計税額を入力してください。

**Q. 登録したのに画面に出てこない**
A. ダッシュボードの **更新** を押してください。会計年度（FISCAL YEAR）が取引日の年度になっているかも確認してください（4月〜翌3月が1年度です）。

**Q. 証憑はどこに保存されている？**
A. Google ドライブ「とうじょうRMO会計システム ＞ 証憑 ＞ 年-月」フォルダです。ダッシュボードの仕訳一覧の「開く」からも見られます。

**Q. 「登録できませんでした」と表示された**
A. メッセージに不足している項目が表示されます（例：資金原資を選んでください）。入力し直して再度登録してください。解決しない場合はエンジニアに連絡してください。

## 用語集

| 用語 | 意味 |
|---|---|
| 支払基準 | 実際にお金が動いた日に記録する方法 |
| 証憑（しょうひょう） | 領収書・請求書・レシートなど、取引を証明する書類 |
| 仕訳 | 取引を「借方」と「貸方」に分けて記録したもの |
| 借方・貸方 | 仕訳の左側・右側。支払の場合、借方が費用、貸方が支払元 |
| 資金原資 | その支出の財源（RMO交付金／自己資金） |
| 事業 | その収入・支出がどの事業のものか（共通＝どの事業とも特定できない） |
| 粗利 | 事業ごとの売上 − 原価 |
| 一般管理費 | どの事業とも特定できない費用（事業「共通」の費用） |
| 立替 | 個人が団体の代わりに支払うこと。後で精算（返金）する |
| 未払金 | 立替などで、まだ返していないお金 |
| 予算コード | 予算の小項目ごとの番号（B001 など） |
| 当初予算・改訂予算 | 最初に決めた予算と、その後に見直した予算 |
| 執行率 | 予算のうち、どれだけ使ったかの割合 |
